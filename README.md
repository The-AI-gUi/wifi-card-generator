# 📶 WiFi Card Generator

![WiFi Card Generator Banner](assets/banner.png)

Generate beautiful, printable WiFi cards with QR codes in seconds.

A modern WiFi QR generator featuring live preview, responsive design, printable cards, community QR links, and premium card-style visuals.

Built by **The AI GUY 👽🤖**

- 📡 Live WiFi QR Code Generation

- 🛡️ WEP Support
- 👻 Hidden Network Support
- 🖨️ Print-Ready WiFi Cards
- 🔄 Interactive Front & Back Card Design

- 🎨 Modern Dark Theme UI

- 📷 Easy Smartphone Scanning
- 📢 Telegram Community QR Integration

## 📋 How It Works

1. Enter your WiFi network name (SSID).
2. Enter the WiFi password.
3. Select the security type.
4. Enable hidden network mode if needed.
5. Choose what appears on the back of the card.
6. Print the card.
7. Let users scan the QR code to connect instantly.
